# Viewrail Leadership Coach

An AI-powered coaching partner built exclusively for leaders at Viewrail. Grounded in the six **Leadership Performance Drivers**, this plugin helps leaders prepare for difficult conversations, build change narratives, practice through role play, and grow through reflection.

## Components

| Component | Name | Purpose |
|-----------|------|---------|
| Skill | `leadership-coach` | Full coaching framework — triggers automatically on coaching-related requests |
| Command | `/coach` | Shortcut to launch the coaching menu directly |

## Usage

### Option 1 — Natural language
Simply describe what you need and the coaching skill will activate:
- "Help me prepare for a difficult conversation with my team member"
- "I need to build a change narrative for a process change"
- "Coach me through a mindset reframe"
- "Let's role play a performance conversation"

### Option 2 — Slash command
Use `/coach` to launch the full coaching menu, or jump directly to a feature:
- `/coach` — Opens the menu
- `/coach difficult conversation` — Goes straight to Feature 1
- `/coach role play` — Goes straight to Feature 3

## The Seven Coaching Features

1. **Prepare for a Difficult Conversation** — Structured support before a high-stakes conversation
2. **Build a Change Narrative** — Craft a message that creates genuine buy-in
3. **Role Play & Practice** — Practice with AI playing the other person, graded debrief included
4. **Reflection Journal** — Debrief a leadership moment and extract learning
5. **Scenario Library** — Generate a realistic Viewrail scenario to practice with
6. **Mindset Reframe** — Work through situations where you feel stuck or resistant
7. **Coaching Conversation Planner** — Prepare for 1:1s so you show up as a coach, not an advice-giver

## The Six Leadership Performance Drivers

All coaching is grounded in these drivers:

1. Develops People Through Coaching
2. Leads With an Outward Mindset
3. Builds Trust & Psychological Safety
4. Empowers Through Ownership
5. Drives Clarity & Purpose
6. Practices Courageous Stewardship

Full driver details: https://sites.google.com/viewrail.com/viewrail/performance-drivers/leadership

## Setup

No additional setup or configuration required. Install and start coaching.
