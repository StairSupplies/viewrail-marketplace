Activate the `a3-problem-solving` skill. Claude will interview you through the seven sections of an A3, push back on weak answers, render a Viewrail-styled DOCX, and offer to submit it to the shared A3 Library on Google Drive.

If an argument is provided (e.g. `/a3 update`, `/a3 list`, `/a3 <title-substring>`), pass it as the initial command to the skill so it can route to the right entry point (new, resume, edit, list).
